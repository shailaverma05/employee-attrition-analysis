# Employee Attrition Analysis

Analysis of employee attrition (turnover) to identify key drivers behind why employees leave and to support data-informed retention decisions.

## Project Structure

- `data/` — Raw and processed datasets used for the analysis
- `notebooks/` — Jupyter notebooks for exploratory data analysis and modeling
- `sql/` — SQL scripts used for data extraction and transformation
- `dashboard/` — Dashboard files for visualizing attrition trends and insights
- `images/` — Charts, screenshots, and other visual assets
